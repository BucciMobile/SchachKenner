PGN Mentor 5.0 is now available. The latest version of PGN Mentor is available by downloading pgnmentor5.exe.

Non-registered users can download pgnmentor5.exe to install a demo version of PGN Mentor 5.0.The program has certain built-in limitations, but has full capability for reading and viewing of PGN files. Also, full functionality is supported for four demo PGN files which are included with the installation.

Pgndemo contains a collection of games played by Kasparov through mid 2001. Pgndemo2 contains the games from the famous 1953 Zurich International tournament featuring grandmasters such as Petrosian, Keres, Bronstein and Najdorf. Pgndemo3 contains the games from the 2002 U.S. Chess Championships. Pgndemo2 and Pgndemo3 are included for use with the functions designed specifically for event files. Pgndemo4 contains annotated games from the 2013 World Chess Championship between Magnus Carlsen and Viswanathan Anand. It is included as an example for viewing annotated games.

Registered users can download pgnmentor5.exe to upgrade to the latest version of PGN Mentor. The program will be fully functional if the setup program has been run. PGN Mentor 5.0 was last updated on September 14, 2017.
