# 11 · Datasets & machine learning

[Back to README](../README.md)

| Dataset | Size / content | Access / license | Link |
|---|---|---|---|
| lichess standard rated games | ~100M+ games/month, PGN + clock comments | Free download | https://database.lichess.org/ |
| lichess puzzles | 6M+ rated/tagged positions | Free download | https://database.lichess.org/#puzzles |
| lichess DB tooling | Code that produces the dumps | Open source (AGPL) | https://github.com/lichess-org/database |
| Hugging Face — Lichess/chess-puzzles | Puzzle DB, ML-ready, monthly updates | Free | https://huggingface.co/datasets/Lichess/chess-puzzles |
| Kaggle — chess datasets | Puzzle DB + game collections for notebooks | Free | https://www.kaggle.com/datasets?search=chess |
| Hugging Face — chess datasets | Search all chess datasets (FEN, games, evals) | Free | https://huggingface.co/datasets?search=chess |
| Opening names dataset | ECO codes + names (used by lichess & co.) | Open data | https://github.com/lichess-org/chess-openings |
