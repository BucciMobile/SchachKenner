# 6 · Analysis software & GUIs

[Back to README](../README.md)

Free desktop/web tools to analyze games with engines, manage databases and run engine matches.

| Tool | Platform | What it does | License / access | Link |
|---|---|---|---|---|
| lichess (web + local analysis) | Web, all OS | Analysis board with Stockfish, studies, broadcasts, cloud eval | Free, open source (AGPL-3.0) | https://lichess.org/ |
| BanksiaGUI | Win/macOS/Linux | Modern free GUI: engines, DB, tournaments, online play | Free (donations) | https://banksiagui.com/ · https://banksiagui.com/download/ |
| Scid vs. PC | Win/macOS/Linux | Database manager + analysis, works with huge PGN collections | Open source (GPL) | https://scidvspc.sourceforge.net/ |
| Arena | Win/Linux | Engine GUI with books, Chess960, DGT board support | Free | http://www.playwitharena.de/ |
| Cute Chess | Win/macOS/Linux | Run engine tournaments/matches (CLI + GUI), SPRT testing | Open source (GPL-3.0) | https://github.com/cutechess/cutechess |
| En Croissant | Win/macOS/Linux | Repertoire preparation + opening explorer + game DB | Open source (GPL-3.0) | https://encroissant.org/ |
| ChessBase / Fritz | Win/macOS | Commercial reference tools | Commercial — link only | https://en.chessbase.com/ |
