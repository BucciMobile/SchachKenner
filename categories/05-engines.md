# 5 · Chess engines (open source)

[Back to README](../README.md)

Engines speak UCI/XBoard and are used by the GUIs in [category 6](06-analysis-gui.md).
All code is open source (typically GPL-3.0) — link to the repos, don't vendor binaries.

| Engine | Notes | License | Link |
|---|---|---|---|
| Stockfish | The strongest open-source engine (NNUE) | GPL-3.0 | https://github.com/official-stockfish/Stockfish |
| Leela Chess Zero (lc0) | Neural-network engine, GPU-friendly | GPL-3.0 | https://github.com/LeelaChessZero/lc0 |
| Fairy-Stockfish | Stockfish fork for variants: Xiangqi, Shogi, Crazyhouse, Chess960, … | GPL-3.0 | https://fairy-stockfish.github.io/ |
| More engines | Berserk, Stormphrax, PlentyChess, Obsidian, Ethereal, Weiss, Koivisto, Seer, … | Mostly GPL-3.0 | https://github.com/topics/chess-engine · https://www.linuxlinks.com/best-free-open-source-chess-engines/ |
